<objective>
Implementare una dashboard admin **view-only** per visualizzare i **carrelli abbandonati** dell'e-commerce, accessibile da `/admin/carrelli-abbandonati`. La dashboard mostra KPI aggregati (count, valore potenziale €, ripartizione loggati/ospiti), una tabella filtrabile per range temporale + tipo utente (URL-driven), e un drill-in di dettaglio con tutti gli item del cart (varianti, selectedOptions, prezzi).

**Definizione operativa di "carrello abbandonato"** (verificata da `src/lib/orders.server.ts:310-312`): un `Cart` è considerato abbandonato sse:
- ha almeno 1 `CartItem` (`items: { some: {} }`), e
- `updatedAt < (now - threshold)` con threshold ∈ {1h, 24h, 7gg, 30gg}, e
- `expiresAt > now()` (cart ancora valido).

**Nessuna cross-check con Order necessaria.** Il pattern post-checkout in `orders.server.ts` esegue `prisma.cartItem.deleteMany({ where: { cartId: cart.id } })` e poi bumpa `updatedAt`: i carrelli effettivamente convertiti in ordine restano riga `Cart` MA con `items` vuoti, quindi naturalmente esclusi dal filtro `items.some`. Questo è documentato nel codice e va annotato in un commento del file `admin-carts.server.ts`.

Purpose: dare all'admin uno strumento di osservabilità sui dropoff del funnel di checkout, senza touchpoint sul cliente (no recovery email, no modifica). Volume atteso basso (<1000 cart abbandonati attivi), full scan accettato (no nuovo indice DB).

    **Helper interno** `buildWhereClause(threshold, userFilter, now)`:
    ```ts
    function buildWhereClause(threshold: ThresholdRange, userFilter: UserFilter, now: Date) {
      const thresholdDate = new Date(now.getTime() - thresholdToMs(threshold));
      const conditions: Array<Record<string, unknown>> = [
        { items: { some: {} } },                    // almeno 1 item
        { updatedAt: { lt: thresholdDate } },       // più vecchio della soglia
        { expiresAt: { gt: now } },                 // cart ancora valido
      ];
      if (userFilter === "logged") conditions.push({ userId: { not: null } });
      else if (userFilter === "guest") conditions.push({ userId: null });
      return { AND: conditions };
    }
    ```
