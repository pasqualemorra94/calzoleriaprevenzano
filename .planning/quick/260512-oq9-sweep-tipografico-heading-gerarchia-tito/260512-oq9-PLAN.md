Scala "Sobrio" (usare le utility Tailwind ora collegate ai token):

| Ruolo | Classi |
|---|---|
| Hero H1 (solo HeroSection) | LASCIARE com'è — inline style clamp dedicato, NON toccare |
| Eyebrow / kicker | `text-xs font-semibold uppercase tracking-widest text-[var(--color-accent)]` |
| Titolo di sezione H2 | `font-display text-3xl font-semibold tracking-tight text-balance text-[var(--color-text)]` |
| Lead / intro di sezione | `text-lg leading-relaxed text-[var(--color-text-secondary)]` + `max-w-*` di prosa + `mx-auto` se centrato |
| Titolo di card / blocco H3 (deve essere sempre < H2) | `font-display text-xl font-semibold tracking-tight text-balance text-[var(--color-text)]` (stessa taglia featured e non-featured) |
| Testo card / paragrafo | `text-base leading-relaxed text-[var(--color-text-secondary)]` |
| Meta / label / badge | `text-xs font-medium` (+ `uppercase tracking-wide` quando badge) |
| CTA link inline | `text-sm font-medium text-[var(--color-accent)]` |

Note:
- `text-*` sono fluide → rimuovere le coppie `md:text-...` ridondanti dove il valore fluido già copre il range.
- Preservare il "DNA" visivo: stitch lines / divider decorativi (`<span className="h-px w-8 bg-...">`, pattern di trattini, stitch corner accents) NON vanno rimossi — vengono passati a SectionHeader via prop `decoration` o lasciati nel JSX della sezione.
- `--color-text` e `--color-foreground` sono lo stesso valore (#2D2D2D); usare `--color-text` come da scala. `--tracking-widest` = 0.1em.
