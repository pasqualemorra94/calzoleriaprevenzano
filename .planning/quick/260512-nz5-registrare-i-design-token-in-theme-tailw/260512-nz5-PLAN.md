<notes>
Tailwind v4 `@theme` namespace rilevanti:
- `--font-*`        → genera `font-display`, `font-body`
- `--text-*`        → genera `text-xs ... text-7xl` (font-size)
- `--text-*--line-height` → line-height accoppiato a quella size (Tailwind lo emette insieme a `text-N`)
- `--color-*`       → genera `text-*`, `bg-*`, `border-*` ecc. (i default gray-* ecc. restano)
- Spacing: namespace v4 è `--spacing-*` (NON `--space-*`). I token attuali sono `--space-*` e il codice usa
  quasi sempre `var(--space-md)` arbitrario → NON registrarli ora (fuori scope, rischio/scope non giustificato).
- `--radius-*` → genera `rounded-*`; il codice usa `var(--radius-*)` arbitrario → opzionale, basso valore, SKIP per ora.
</notes>
