(text-accent allineato alla scala "Sobrio" per i link CTA.)
   - Animazione espansione: semplice — wrappa il container in `AnimatePresence` + `m.div` con `initial={{ height: 0, opacity: 0 }} animate={{ height: "auto", opacity: 1 }} exit={{ height: 0, opacity: 0 }} transition={{ duration: 0.22 }}` e `overflow-hidden` (motion già presente, niente librerie nuove). Padding interno (`pt-3 pb-1` o simile) su un wrapper figlio del `m.div` (non sul `m.div` stesso, per evitare salti d'altezza).
4. **Fetch dei children di sandali**: `useState<CategoryItem | null>(sandaliCategory)` + `useEffect` che chiama `fetch("/api/categories")` una sola volta (al mount), parsa `json.data as CategoryItem[]`, trova `data.find(c => c.slug === "sandali")` e lo salva in stato.
