**A. Crea `src/lib/discount.server.ts`** (server-only, helper puro — NON incrementa usedCount):

Esporta `interface DiscountResult { valid: boolean; discountAmount: number; error?: string }` e:
```typescript
export async function validateDiscountCode(code: string, subtotal: number): Promise<DiscountResult>
```
Logica (single source of truth, copiata 1:1 da orders.server.ts:180-201, SENZA l'increment riga 202):
- `const row = await prisma.discountCode.findFirst({ where: { code: code.toUpperCase(), isActive: true, startsAt: { lte: new Date() }, expiresAt: { gte: new Date() } } });`
- se `!row` → `return { valid: false, discountAmount: 0, error: "Codice non valido o scaduto" };`
- se `row.minOrder && subtotal < Number(row.minOrder)` → `return { valid: false, discountAmount: 0, error: \`Ordine minimo: €${Number(row.minOrder)}\` };`
- se `row.maxUses && row.usedCount >= row.maxUses` → `return { valid: false, discountAmount: 0, error: "Codice sconto esaurito" };`
- calcola `const discountAmount = row.type === "percentage" ? Math.round(Number(row.value) * subtotal / 100 * 100) / 100 : Math.min(Number(row.value), subtotal);`
- `return { valid: true, discountAmount };`
Import `prisma` da `~/lib/db.server`. Zero `any`. Nessun increment, nessuna mutazione.
